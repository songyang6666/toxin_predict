# Raw data

This directory contains the workbook required by the total microcystin prediction
workflow:

- `western_lake_erie_water_quality_2012_2022.xlsx`

The workflow uses the sheet `2012-2022_surface_predict_toxi`. The source
water-quality data are publicly available from NOAA National Centers for
Environmental Information:

- https://doi.org/10.25921/11da-3x54

The MIT License in the repository root applies to the analysis code, not to
third-party source data. Users should cite the NOAA dataset and follow its
applicable terms.
